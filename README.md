# Online Shoppers Purchasing Intention — ДЗ #1 

Исследование: что определяет, закончится ли сессия в интернет-магазине покупкой, и какая модель предсказывает это лучше всего.

## Датасет и почему он

[Online Shoppers Purchasing Intention](https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset) — 12 330 сессий, 17 признаков, цель `Revenue` (покупка / нет).

*Почему выбрал:* бинарная классификация с реальным дисбалансом классов, смесь числовых и категориальных признаков

Файл с данными лежит в репозитории: `online_shoppers_intention.csv`.

## Гипотезы (сформулированы до экспериментов)

**Гипотеза 1. Accuracy обманывает** Модель «никто не купит» получит accuracy ≥ 0.8, но F1 по покупкам у неё 0, а обученная модель поднимет accuracy лишь ненамного.

**Гипотеза 2. PageValues — главный признак**: PageValues — самый важный признак, и модель, обученная только на нём, уже даёт ROC-AUC ≥ 0.85.

**Гипотеза 3. Хватит 8 признаков** Если оставить 8 лучших признаков (SelectKBest), ROC-AUC упадёт меньше чем на 0.01.

**Гипотеза 4. Бустинг и Random Forest лучше логрегрессии** По PR-AUC бустинг или Random Forest обгонят логистическую регрессию минимум на 0.03, потому что зависимости нелинейны.

**Гипотеза 5. Лучшая глубина дерева по CV лежит в 3–8.** При глубине ≥ 15 CV ROC-AUC падает на 0.03 и более от пика, а train ROC-AUC выше 0.98.

## Краткие результаты


| Гипотеза | Вердикт | Коротко почему |
| :--- | :---: | :--- |
| **Гипотеза 1.** Accuracy обманывает | **Подтвердилась** | Dummy («никто не купит») даёт accuracy 0.844 при F1 = 0; лучшая модель поднимает accuracy лишь до 0.90–0.91 (+6 п.п.), но F1 — с 0 до 0.65–0.69: accuracy измеряет угадывание большинства (84.5% сессий без покупки), а не поиск покупателей. |
| **Гипотеза 2.** PageValues — главный признак | **Подтвердилась** | Модель только на PageValues даёт ROC-AUC 0.860 (≥ 0.85); 1-е место в permutation importance (падение PR-AUC 0.542, следующий признак Month — 0.043): PageValues — денежная ценность просмотренных страниц, ненулевая только при доходе сессии до корзины/оформления (у покупателей среднее 27.3 против 2.0). |
| **Гипотеза 3.** Хватит 8 признаков | **Частично** | При k=8 падение ROC-AUC у LogReg 0.009 (< 0.01, условие выполнено), у HistGB 0.012 (> 0.01): SelectKBest забирает все признаки с сильным одиночным сигналом (PageValues, ProductRelated(+Duration), Administrative(+Duration), BounceRates, ExitRates, Month_Nov) — линейной модели этого хватает, бустинг добирает слабые совместные эффекты остальных. |
| **Гипотеза 4.** Бустинг и Random Forest лучше логрегрессии | **Подтвердилась** | PR-AUC: LogReg 0.685 (CV после подбора), RandomForest 0.756, HistGB 0.755 — разница ≈ 0.07 ≥ 0.03 (на test 0.697 vs 0.757/0.758): зависимость покупки от признаков нелинейна (порог по PageValues, сезонность Month), деревья ловят её без ручных трансформаций. |
| **Гипотеза 5.** Лучшая глубина дерева по CV лежит в 3–8 | **Подтвердилась** | Пик CV ROC-AUC 0.915 при depth = 4 (входит в 3–8); при depth ≥ 15 train ROC-AUC 0.999 (> 0.98), а CV падает на 0.161 от пика (≥ 0.03): неограниченное дерево запоминает шум train, обобщение деградирует — классическое переобучение. |

**Лучшая модель:** **RandomForest** по CV PR-AUC (0.756; HistGB рядом — 0.755, различие в пределах std по фолдам 0.016–0.022) (PR-AUC на test = 0.757, F1 = 0.690 при подобранном пороге 0.37; у HistGB PR-AUC 0.758, F1 0.694 при пороге 0.33).
